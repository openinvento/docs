# Translations & Localization

OpenInvento is designed to be accessible to users worldwide. Translating OpenInvento into your native language is one of the most impactful ways to contribute to the project!

---

## Architecture Overview

The OpenInvento frontend uses `react-i18next` for all localization:
- Translation dictionaries are stored as JSON files inside `frontend/src/locales/` (or equivalent translation directory).
- All UI strings are mapped to hierarchical keys (for example, `common.save`, `articles.actions.delete`).

---

## Recommended Tool: i18n Ally

For local development in Visual Studio Code, we strongly recommend the **[i18n Ally](https://marketplace.visualstudio.com/items?itemName=Lokalise.i18n-ally)** extension.

With i18n Ally:
- You see inline translations directly inside JSX/TSX files instead of raw translation keys.
- Missing translation keys are automatically highlighted in your editor.
- You can add or edit translations in multiple languages side-by-side with a single click.

---

## Translation Guidelines

When adding or updating translations:

1. **Use Nested JSON Keys**: Keep related strings grouped logically:
   ```json title="frontend/src/locales/en.json"
   {
     "inventory": {
       "title": "Inventory Overview",
       "empty": "No items found",
       "actions": {
         "create": "New Item",
         "export": "Export CSV"
       }
     }
   }
   ```
2. **Never Hardcode Text**: If you find an untranslated string in the UI, replace it with a call to `t('...')` and add the corresponding key in all locale files.
3. **Keep Tone Clear and Consistent**: Use standard terminology for common actions (*Save*, *Cancel*, *Delete*, *Confirm*).

---

## Adding a New Language

To contribute a new language to OpenInvento:

1. Copy the English strings `frontend/src/locales/en.json` to `frontend/src/locales/<language-code>.json` (e.g. `it.json`).
2. Translate the string values into your target language. Keep the keys and the `{{placeholders}}` unchanged.
3. Import the file and add it to `resources` in the frontend i18n initialization file (`frontend/src/i18n.ts`).
4. Add the language to the language selector in `frontend/src/components/settings/UserSettings.tsx`: a `SelectItem` with the language code, and its name in `languageName`.
5. Run `pnpm i18n:check` in `frontend/`. It checks every locale file against `en.json` for missing keys and placeholders.
6. Verify your translations locally by starting the frontend development server and selecting the new language from your profile settings.
7. Open a pull request on GitHub and remember to post the required CLA agreement comment!
