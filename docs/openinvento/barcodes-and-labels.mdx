# Barcodes & QR Labels

Physical inventory is only as good as your ability to identify and locate items quickly. OpenInvento includes built-in barcode and QR code capabilities to streamline item tracking, scanning, and label printing.

---

## Unique System Identifiers

Every component in OpenInvento—including **Areas**, **Shelves**, **Boxes**, and **Articles**—is automatically assigned a unique alphanumeric **identifier** (e.g. `7GQ2MX4`). New identifiers use uppercase letters and digits only, without the easily confused `I`, `L`, `O` and `U`; entries created with older versions may still have mixed-case identifiers.

These identifiers are:
- Compact and optimized for fast barcode rendering and camera scanning.
- Permanent and uniquely indexed across your inventory.
- Human-readable directly below the code on printed labels.

---

## Generating Printable PDF Labels

OpenInvento allows you to export ready-to-print PDF label sheets tailored for standard label paper or sticker sheets:

1. Select one or more items (articles, boxes, shelves, or areas) from the inventory view.
2. Click **Print Labels** in the action toolbar.
3. Choose your print preferences:
   - **Code Type**:
     - `QR Code`: High-density 2D matrix code; easily scanned by smartphones even at smaller dimensions.
     - `Barcode (Code128)`: Standard 1D linear barcode; ideal for handheld laser or optical USB/Bluetooth scanners.
   - **Paper Size**: `A4`, `A5`, or `Letter`.
   - **Sheet Layout**:
     - `Vertical`: 4 columns &times; 2 rows (8 labels per page).
     - `Horizontal`: 2 columns &times; 4 rows (8 labels per page).
   - **Error Correction** (QR codes only):
     - `Medium` (recommended): still readable when part of the code is scratched or dirty.
     - `Low`: a smaller code, but less tolerant of damage.
4. Click **Generate PDF** to download the label sheet.

### Printed Label

Each printed cell includes:
1. **Item Title**: Bold item name (up to 32 characters).
2. **Code**: Centered high-resolution vector QR code or Code128 barcode.
3. **Reference Footer**: Object type and identifier (e.g., `article: 7GQ2MX4` or `box: K4B1L9V`).

### What a QR Code Contains

A QR code contains a link to its entry, so any phone camera app can open it, not only the scanner in OpenInvento:

```text
https://inventory.example.com/i/{inventory identifier}/{identifier}
```

- **Smaller codes:** if both identifiers only use uppercase letters and digits, the whole link is written in uppercase, like `HTTPS://INVENTORY.EXAMPLE.COM/I/K7M2Q/7GQ2MX4`. QR codes store uppercase text much more compactly, so the code gets smaller or more robust. Entries with older mixed-case identifiers get the same link in lowercase.
- **Opening a link:** OpenInvento asks for a login first if needed, then opens the entry and switches to its inventory. A code that doesn't exist, or belongs to an inventory you're not a member of, shows "Code not found".
- **Only an identifier:** without `APP_URL`, the QR code holds just the identifier, as Code128 barcodes always do. Identifiers `.` and `..` also stay without a link, because such a link can't reach the entry.
- **Turning links off:** administrators can switch this off under **Settings** &rarr; **Admin settings (instance)** &rarr; **URLs in QR codes**. QR codes then hold only the identifier.
- **Before printing:** while links are on, the label options show which address the QR codes point to.

:::caution
Moving your instance
Printed links point to the address they were printed with. If your instance moves to another address, those labels stop opening their entries. To keep labels valid across moves, point QR codes at a short address of your own with [`SCAN_BASE_URL`](../setup-installation/configuration#links-in-qr-codes-scan_base_url), which redirects to your instance.
:::

## Scanning & Fast Lookups

When you need to find an item or verify what is stored inside a box:

1. Open **Code Management** in the sidebar.
2. Click **Scan a code** to use the camera, or the **External Barcode Scanner** button next to it to use a barcode scanner.
3. OpenInvento opens the article, box, shelf, or area that belongs to the code.

The scanner reads the links in QR codes, plain identifiers, and the [product barcodes](#product-barcodes) stored on articles:

- **Identifiers first:** a code that is an entry's identifier always opens that entry, even if an article has the same number as a barcode.
- **Then product barcodes:** otherwise OpenInvento looks for articles with that barcode, starting with the selected inventory, then in all other inventories you're a member of.
- **Several matches:** the same product can be stored in several places, for example a spare pack in the cellar and an open one in the kitchen. Then a list shows every match with its inventory, and you pick the one you mean.

You can also scan a QR code with your phone's camera app outside OpenInvento: it opens the entry in the browser.

### External Barcode Scanners

Most handheld USB and Bluetooth scanners work in keyboard mode: they type the code and press Enter, like a keyboard would. The **External Barcode Scanner** button opens a field for them. Scan into it, or type a code and press Enter. The same field is on the [barcode import](./smart-import-third-party#barcode-import) page.

## Product Barcodes

Articles can store the barcodes printed on their packaging, so scanning the package finds the article. Add them in the **Barcodes** section of an article, when creating or editing it:

| Type | What it is | Check |
| :--- | :--- | :--- |
| `EAN / UPC` | The barcode on most retail products (EAN-8, UPC-A, EAN-13, GTIN-14) | check digit |
| `ISBN` | Books, ISBN-10 or ISBN-13 | check digit |
| `PZN` | German pharmacy number on medicine packs (PZN7 or PZN8) | check digit |
| `Other` | Anything else, for example an internal part number | none |

- **Detect type:** leave the type on *Detect type* and OpenInvento picks it from the number. A PZN looks like an EAN-8, so choose `PZN` yourself for medicine.
- **Spelling:** spaces and hyphens are removed, and a leading `PZN` is dropped, so `978-3-16-148410-0` and `9783161484100` are the same ISBN.
- **Check digits:** a number with a wrong check digit is rejected, usually because of a typo. If the code really is like that, save it as `Other`.
- **Several barcodes:** an article can have several, for example when the packaging changed, or a medicine pack carries both a PZN and an EAN. Several articles can share a barcode too.

Serial numbers stay a category field (`serial_number` in **Electronics**), because every device has its own. Scanning doesn't search category fields.

:::note
Upgrading from v1.5.0 or earlier
The default fields `barcode` (**Food**), `isbn` (**Books**) and `pzn_barcode` (**Medicine**) are replaced by product barcodes. Their values are moved into the articles' barcodes when you upgrade, and the three fields are removed. A value that doesn't pass the check digit is kept as `Other`.
:::
