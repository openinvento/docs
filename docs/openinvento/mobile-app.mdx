# Mobile App

To use OpenInvento on mobile devices, just install your OpenInvento Frontend as a PWA.

Progressive Web Apps (PWA) are web applications that can be installed on your device and run like native apps.

---

## PWA installation on iOS
1. Open Safari and navigate to your OpenInvento instance (e.g., `https://yourdomain.com`).
2. Tap the **Share** button (the square with an arrow pointing up).
3. Scroll down and select **Add to Home Screen**.
4. Confirm the name and tap **Add**. The OpenInvento icon will now appear on your home screen.

---

## PWA Installation on Android

1. Open Chrome or another supported browser and navigate to your OpenInvento instance (e.g., `https://yourdomain.com`).
2. Tap the **More** button (the three dots in the top-right corner).
3. Select **Add to Home Screen**.
4. Confirm the name and tap **Add**. The OpenInvento icon will now appear on your home screen.
