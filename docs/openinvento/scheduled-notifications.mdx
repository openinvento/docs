# Scheduled Notifications

OpenInvento runs daily background jobs for date-field notifications, low-stock notifications, and update checks. Each job has its own configurable time. All three jobs default to midnight UTC (`00:00`).

## Configure job times

Set the following environment variables using 24-hour `HH:MM` values in **UTC**. OpenInvento runs in UTC regardless of the host's or container's time zone, so convert your local time: for 08:00 in Berlin (UTC+1 in winter, UTC+2 in summer), set `07:00` or `06:00`.

| Variable | Default | Job |
| :--- | :---: | :--- |
| `DATE_FIELD_NOTIFICATION_TIME` | `00:00` | Sends notifications for configured date fields. |
| `LOW_STOCK_NOTIFICATION_TIME` | `00:00` | Sends low-stock notifications. |
| `UPDATE_CHECK_TIME` | `00:00` | Checks for OpenInvento updates. |

For example, to schedule notifications in the morning and the update check later:

```dotenv
DATE_FIELD_NOTIFICATION_TIME=08:00
LOW_STOCK_NOTIFICATION_TIME=08:30
UPDATE_CHECK_TIME=09:00
```

## Control the scheduler

`ENABLE_TASK_SCHEDULER` controls whether the daily task scheduler starts. Set it to `false` to disable all scheduled jobs.

`ENABLE_UPDATE_CHECKER` controls whether the update check is registered. It does not disable the date-field or low-stock notification jobs.
