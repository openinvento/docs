# Additional Modules

OpenInvento has some additional modules included to extend the functionality of your system. These modules are optional and can be enabled or disabled based on your specific needs.

## Manage modules
Go to **Settings** &rarr; **Admin settings (instance)** &rarr; **Modules** to enable or disable the available modules. After enabling a module, the corresponding features should be available in the OpenInvento interface.


## Module Overview

### Loan module
The Loan module allows you to manage the lending of items to users or departments. It provides features for tracking loaned items, due dates, and return statuses.
