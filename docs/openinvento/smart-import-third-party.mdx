# Smart article import - Third party integrations
You can import articles from third-party sources using the OpenInvento smart import feature. There are providers available for barcode lookup and vision AI detection.

## Configuring third party providers
Open Inventory Settings > Third Party Integrations to configure the providers. You can enable or disable each provider and set the API key and other settings for each provider.

## Supported providers

### Barcode lookup
- OpenFoodFacts (No API key required)

### Vision AI detection
- Google Gemini API (API key required)
- Ollama local model (No API key required, set `OLLAMA_API_URL` as env variable!)
