# Secret Key Management

## Configuring the Secret Key
Use the `SECRET_KEY` environment variable to set your secret key. This key is used for encrypting sensitive data and should be kept secure.
You can generate a new secret key using the following command:

```bash
openssl rand -base64 32
```

## Change the Secret Key

To change the secret key, update the `SECRET_KEY` environment variable with a new value.
:::warning

After changing the secret key, all previously encrypted data will become inaccessible. Ensure you have backups of any critical data before making this change.

For example, API keys (from third party providers like LLMs) are encrypted using the secret key. If you change the secret key, you will need to re-enter these API keys in the application settings.

:::
